Behandlingsansvarlig

Nithusan Krishnasamymudali er behandlingsansvarlig for interesselisten. Henvendelser kan sendes via kontaktinformasjonen på supportsiden.

Interesselisten

Når du registrerer deg, lagrer Poengjeger e-postadressen din og tidspunktet for samtykket. Opplysningene brukes bare til å sende informasjon om pilot eller lansering av Poengjeger.

Behandlingsgrunnlag og lagring

Behandlingen bygger på samtykket ditt. Opplysningene lagres hos Supabase og deles ikke for markedsføring av andre tjenester. De slettes senest tolv måneder etter at siste beskjed om pilot eller lansering er sendt, eller tidligere dersom du trekker samtykket.

Dine rettigheter

Du kan be om innsyn, retting eller sletting, og du kan når som helst trekke samtykket. Se supportsiden for kontaktinformasjon.

Nettsiden

Nettsiden bruker ikke annonse- eller sporingsinformasjonskapsler. Tekniske logger kan behandles av GitHub Pages og Supabase for sikkerhet og drift.
