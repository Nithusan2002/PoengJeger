# Poengjeger produktside

Statisk landingsside for Poengjeger. Appbildene er bevisst markert som
plassholdere og skal erstattes når endelige skjermbilder er klare.

## Lokal forhåndsvisning

```sh
python3 -m http.server 4187 --directory public-site
```

Åpne deretter `http://127.0.0.1:4187`.

## Publisering

Mappen inneholder bare statiske filer og kan publiseres på GitHub Pages eller
en tilsvarende statisk vert. Ingen nøkler eller backendkonfigurasjon skal legges
i denne flaten.
